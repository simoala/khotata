# الموقع تحت الصيانة

هذه النسخة الحالية من الموقع تعرض صفحة **«الموقع تحت الصيانة»** فقط.

## الملفات

```
index.html   صفحة الصيانة
.nojekyll    لتعطيل Jekyll على GitHub Pages
```

## النشر على GitHub Pages

ارفع `index.html` و `.nojekyll` إلى المستودع، ثم من `Settings` ← `Pages`
اختر **Branch: main** و **Folder: / (root)**.

> نسخة الموقع الكاملة (مولّد الخطاطات الذهنية) محفوظة ويمكن إرجاعها عند انتهاء الصيانة.
