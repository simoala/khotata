# مولّد الخطاطات الذهنية من عروض PPTX

موقع صغير يشتغل **كاملا داخل المتصفح**: ترفع عرض الحصة بصيغة `.pptx`، فيستخرج محتواه
(الأهداف، الوسائل، مراحل الحصة الأربع وأنشطتها) ويبني منه خطاطة ذهنية بالأبيض والأسود
في صفحة A4 عمودية جاهزة للطباعة أو الحفظ PDF.

لا يُرفع أي ملف إلى أي خادم: القراءة والتحليل يتمّان محليًّا عبر JavaScript.

## المزايا

- رفع عدة عروض دفعة واحدة (المسار 1، المسار 2، المسار 3…) وتوليد صفحة لكل مسار.
- استخراج تلقائي: رقم المسار، اللبنة، الحصة، الأهداف، العدة/الوسائل، وأنشطة كل مرحلة.
- تحرير كامل قبل التوليد: كل سطر في مربع نص يمكن تعديله أو حذفه، مع ضبط عناوين المراحل ومددها.
- ترويسة قابلة للتخصيص: اسم الأستاذ(ة)، المدرسة، سطر علوي وسفلي، وخانة تاريخ فارغة.
- الإخراج: طباعة / حفظ PDF (A4 عمودي)، أو تحميل صور PNG عالية الدقة.

## التشغيل محليا

افتح `index.html` مباشرة في المتصفح. لا حاجة إلى أي تنصيب.

## النشر على GitHub Pages

1. أنشئ مستودعا جديدا على GitHub (مثلا `mindmap-pptx`).
2. ارفع إليه ملفات هذا المجلد: `index.html` و `.nojekyll` و `README.md`.
3. من `Settings` ← `Pages`: اختر **Branch: main** و **Folder: / (root)** ثم `Save`.
4. بعد دقيقة يصير الموقع متاحا على:
   `https://<اسم-حسابك>.github.io/mindmap-pptx/`

> ملف `.nojekyll` ضروري حتى لا يتدخل Jekyll في ملفات الموقع.

### أوامر الرفع من سطر الأوامر

```bash
git init
git add .
git commit -m "مولّد الخطاطات الذهنية"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/mindmap-pptx.git
git push -u origin main
```

## ملاحظة حول PHP

**GitHub Pages لا يشغّل PHP** — فهو يقدّم ملفات ثابتة فقط (HTML/CSS/JS).
لذلك بُني هذا الموقع بالكامل بـ HTML + JavaScript حتى يعمل على GitHub Pages دون خادم.

إن كان لديك استضافة تدعم PHP (Infinity Free، Hostinger، XAMPP محليا…)، يوجد في المجلد
`php/` نسخة اختيارية تقوم بالاستخراج على الخادم (`ZipArchive` + `SimpleXML`) وتعيد JSON،
ويمكن للواجهة استعمالها عوض المعالجة المحلية. الملف `php/extract.php` يحتاج فقط إلى
تفعيل إضافة `zip` في PHP.

## البنية

```
index.html        الموقع كاملا (واجهة + تحليل + رسم + طباعة)
.nojekyll         لتعطيل Jekyll على GitHub Pages
php/extract.php   (اختياري) استخراج على الخادم لمن يملك استضافة PHP
```

## المكتبات المستعملة

- [JSZip](https://stuk.github.io/jszip/) لقراءة محتوى ملف `.pptx` (وهو أرشيف ZIP).
- [html2canvas](https://html2canvas.hertzen.com/) لتصدير الصفحات صور PNG.
- خط [Cairo](https://fonts.google.com/specimen/Cairo) من Google Fonts.

## نصائح للطباعة

عند الضغط على «طباعة / حفظ PDF» اختر: الحجم **A4**، الاتجاه **عمودي**،
الهوامش **بلا (None)**، وفعّل **طباعة ألوان ورسوم الخلفية** حتى تظهر العناوين السوداء.
